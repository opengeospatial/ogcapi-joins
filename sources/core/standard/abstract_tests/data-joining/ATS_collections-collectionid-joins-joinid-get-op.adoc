====
[%metadata]
identifier:: /conf/data-joining/collections-collectionid-joins-joinid-get-op
target:: /req/data-joining/collections-collectionid-joins-joinid-get-op
test-purpose:: Validate that the information about a join source can be retrieved from the expected location.
test-method::
+
--
. For each collection listed in the <<collections-op, Collections>> response:
. Issue an HTTP GET request to the URL (path `{root}/collections/{collectionId}/joins`) where `collectionId` is the identifier of each collection to get a list of collection' join sources.
. For each listed join source, issue an HTTP GET request to the URL `{root}/collections/{collectionId}/joins/{joinId}` where `collectionId` is the identifier of each collection and `joinId` is the `id` property of a each join source in the `joins` array.
. Validate that a document was returned with a status code `200`.
. Validate the contents of the returned document using test <<ats_data_joining_collections-collectionid-joins-joinid-get-success, /conf/data-joining/collections-collectionid-joins-joinid-get-success>>.
--
====
