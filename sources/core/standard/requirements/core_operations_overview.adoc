[[core-overview-table]]
.Overview of the resources defined in the OGC API - Joins core module.
[width="95%", cols="15,5,10", options="header"]
|===
^|*Path*|*HTTP method*|*Description*
3+|*Discovery Operations*
|/
|GET
|API landing page.

|/api (recommended path)
|GET
|API definition.

|/conformance
|GET
|API conformance declaration.

3+|*Data Joining Operations*
|/collections
|GET
|Returns metadata on the collections available on the server.

|/collections/{collectionId}
|GET
|Returns metadata on a specific collection available on the server.

|/collections/{collectionId}/keys
|GET
|Returns the key fields of a specific collection.

|/collections/{collectionId}/joins
|GET
|Returns a list of the join sources available on the server that are related to a specific collection.

|/collections/{collectionId}/joins
|POST
|Creates a new join source by saving tabular data from an input data source to the server.

|/collections/{collectionId}/joins/{joinId}
|GET
|Returns metadata on a specific join source.

|/collections/{collectionId}/joins/{joinId}
|DELETE
|Deletes a specific join source.

|/collections/{collectionId}/items
|GET
|Returns the items of a collection. Join source data can be joined with the collection by providing the `joinId` parameter of a join source with the query.

3+|*Direct Joining Operations*
|/direct-join
|POST
|Joins data directly between two input data sources.
|===
