[[req_data_joining_collections_collectionid_items-get-op]]

[requirement]
====
[%metadata]
identifier:: /req/data-joining/collections-collectionid-items-get-op
part:: 
If the server implements __data joining operations__, it SHALL support the HTTP GET operation at the path `{root}/collections/{collectionId}/items`.
part::
The parameter `collectionId` is each id property in the collections response (JSONPath: $.collections[*].id).
====
