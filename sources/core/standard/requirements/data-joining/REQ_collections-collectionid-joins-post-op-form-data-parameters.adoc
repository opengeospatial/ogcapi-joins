[[req_data_joining_collections-collectionid-joins-post-op-form-data-parameters]]

.The Form Data parameters of the Join Source Creation query.
[width="100%", options="header", cols="2,3,1,1"]
|===
^|Name				            | Description 	     | Type and values | Required
^|collectionKey	                | The value of the `id` attribute of an object in the `keys` array in the <<collection-keys-op, Collection's Key Fields>> response of this collection. | String | Optional^a^
^|rightDatasetResourceType      | The resource type of the right dataset. | String | Mandatory^b^
^|rightDatasetMimeType          | The mime type of the right dataset. | String | Mandatory^c^
^|rightDatasetFile              | The right dataset file (uploaded file). | File | Optional^d^
^|rightDatasetUrl	            | A URL link to the right dataset. | String | Optional^e^
^|rightDatasetKey	            | The key field in the right dataset that contains the key values that will be used in the join operation. | String | Mandatory^f^
^|rightDatasetJoinFields        | The fields in the right dataset that will be saved to the join source. | String, separated by commas | Optional^g^
^|rightDatasetOptions           | File format-specific key-value parameter options for the right dataset. | String | Mandatory^h^
4+| ^a^ If the `collectionKey` parameter is not provided in the request, the `id` attribute of the default key field is used. The key values must be shared between the `collectionKey` field and the `rightDatasetKey` field in order to execute a successful join operation.
4+| ^b^  The __rightDatasetResourceType__ parameter value is one of the following: `FileUpload`, `FileURL` or `OgcAPI`. The `FileUpload` value indicates that the right dataset is provided via file upload. The uploaded file is defined with the __rightDatasetFile__ parameter. The `FileURL` indicates that the right dataset is provided via a URL link. The `OgcAPI` value indicates that the right dataset is provided via an external OGC API. The `FileURL` and `OgcAPI` addresses are defined with the __rightDatasetURL__ parameter. For the `OgcAPI` values, the server implementations can choose how they process the input.
4+| ^c^  The __rightDatasetMimeType__ parameter indicates the mime type of the right dataset.
4+| ^d^  The __rightDatasetFile__ parameter is used when the __rightDatasetResourceType__ parameter value is `FileUpload`.
4+| ^e^  The __rightDatasetURL__ parameter is used when the __rightDatasetResourceType__ parameter value is `FileURL` or `OgcAPI`.
4+| ^f^ For the __rightDatasetMimeType__ parameter value `text/csv`, this value is the column name, taken from the CSV file header row, that contains the key values. The key values must be shared between the `collectionKey` field and the `rightDatasetKey` field in order to execute a successful join operation.
4+| ^g^  For the __rightDatasetMimeType__ parameter value `text/csv`, these are the column names, taken from the CSV file header row, that will be saved to the join source. If omitted, all CSV file columns will be saved to the join source.
4+| ^h^  The file format-specific parameters are given as a JSON object that contains key-value pairs. For the __rightDatasetMimeType__ parameter value `text/csv`, the mandatory key is `delimiter` that indicates the csv file's delimiter character. In addition, recommended keys are `headerRow`, that indicates the row number of the csv file's header row (if omitted, header row is expected to be at the first row of the CSV file) and `dataStartRow` that indicates the row number where the data values start (if omitted, data start row is expected to be at the second row of the CSV file).

|===
