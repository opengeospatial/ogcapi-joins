[[req_data_joining_collections-collectionid-get-success]]

[requirement]
====
[%metadata]
identifier:: /req/data-joining/collections-collectionid-get-success
part:: A successful execution of the operation SHALL be reported as a response with a HTTP status code `200`.
part:: The content of that response SHALL be based upon the <<response_schema_for_the_collection,Response Schema for the Collection>>.
part:: The content of the Collection response SHALL be consistent with the content for this collection in the `/collections` response, with the exception of `links` which can contain additional links in the response for the individual Collection description resource. That is, if a property is included in the response to the list of collections at `/collections`, the value for that property of the same collection (the collection whose `id` value corresponds to the {collectionId}) SHALL be identical for response for the Collection description resource (`/collections/{collectionId}`).
====
