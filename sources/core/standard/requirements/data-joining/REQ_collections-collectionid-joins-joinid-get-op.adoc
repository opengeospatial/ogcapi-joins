[[req_data_joining_collections-collectionid-joins-joinid-get-op]]

[requirement]
====
[%metadata]
identifier:: /req/data-joining/collections-collectionid-joins-joinid-get-op
part:: If the server implements __data joining operations__, it SHALL support the HTTP GET operation at the path `/collections/{collectionId}/joins/{joinId}`.
part:: The parameter `joinId` SHALL be each `id` property in the `joins` array in the <<collection-join-sources-op,Collection's Join Sources>> response (JSONPath: `$.joins[*].id`).
====
